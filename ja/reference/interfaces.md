# 信号インターフェース（つなぎ方）

回路図に出てくる「通信・信号の種類」を、役割つきでまとめます。
**「誰と誰が、どんなルールで話すか」**の一覧です。

| 名前 | 種類 | この装置での役割 | 例え |
|---|---|---|---|
| **I²C**（アイスクエアドシー） | シリアル通信 | IMUセンサ6個 → マイコン。傾きデータを送る | 2本の線で複数のチップが順番におしゃべり |
| **UART**（ユーアート） | シリアル通信 | 無線モジュール ⇄ マイコン。リモコン指令をやりとり | 1対1の電話 |
| **D-Aコンバータ**（DAC）＋**アンプ**（PGA） | 出力信号 | マイコン → アナログ指令 → アンプで整えてモータドライバへ | 数字（デジタル）を声（アナログ）に直し、ボリュームで大きさ調整 |
| **ホール・センサ＋パルスカウンタ** | 入力信号 | モータの回転（ホール信号）→ パルスを数えて回転数に。マイコンが読む | 回転を「カチカチ」と数える回転計 |
| **MOSFET**（モスフェット） | スイッチ素子 | マイコン → 電磁ブレーキ。大きな電流をON/OFF | 大電流を素早く入り切りする電子スイッチ |
| **GPIO**（ジーピーアイオー） | 汎用ピン | マイコンの出力ピン。MOSFETをON/OFF | ただの「電気のON/OFFの口」 |

---

## もう少しくわしく

### I²C：センサをたくさんつなぐための通信
- たった**2本の線**（データ線・クロック線）で、複数のチップを数珠つなぎにできる。
- この装置ではIMUを**2個ずつ3グループ**に分けて、3本のI²Cで受けている。
  - 理由：1本に全部つなぐと混雑して遅くなる／同じ住所（アドレス）のセンサがぶつかるのを避ける。

### UART：シンプルな1対1通信
- 送る線と受ける線だけの素朴な通信。
- 無線モジュールをつないで、手元のリモコンと会話する。

### D-A＋アンプ：モータ電流の「指令」の伝え方
- マイコンが計算した「どれくらい回すか」を、**D-Aコンバータ**でアナログ信号（電圧）に変換して出力する。
- それを**可変ゲインのアンプ（PGA）と固定ゲインのアンプ**で信号レベルを整え、**モータドライバ**に渡す。
- ドライバがこの指令に応じてモータへ**駆動電流**を流し、ホイールが回る。

### ホール・センサ＋パルスカウント：モータの回転数を"見張る"ため
- モータドライバは、モータの回転位置を**ホール・センサの信号**として出してくれる。
- それを **パルス・カウント回路** で数えると回転数がわかり、マイコンが「回しすぎてないか」をチェックする。
- 回しすぎたホイールは **アンローディング**（回転を戻す操作）が必要になる（→座学3回目）。

### MOSFET：電磁ブレーキ用の力持ちスイッチ
- マイコンのピンは小さな電流しか流せない。
- 電磁ブレーキには大きな電流が必要 → 間に **MOSFET** を入れて、小さな信号で大きな電流をON/OFFする。

## さらにくわしく（電気・通信の理屈）

> 「なぜこの部品・この本数なのか」を理屈で押さえます。回路を組むときに効いてきます。

### I²C：なぜ「3系統」あるのか（アドレスの話）
- I²Cは **7ビットのアドレス**で相手のチップを指名する。**同じバスに同じアドレスは同居できない**。
- MPU-6050 のアドレスは **AD0 ピン**で決まり、`AD0 = L → 0x68` / `AD0 = H → 0x69` の **2通りだけ**。
- つまり **1本のI²Cバスに載せられるMPU-6050は最大2個**。6個載せるには **6 ÷ 2 = 3本**のバスが必要。
- これが回路図で **I²Cが3系統**ある本当の理由です。（速度・負荷分散の意味もありますが、本質は"アドレスが2個しかない"制約）
- 補足：SDA/SCL は**オープンドレイン**なので**プルアップ抵抗**が必要。マスタ（マイコン）がクロックを出し、スレーブ（センサ）が応答します。

### 指令電圧 → 電流 → トルク の橋渡し
- D-Aコンバータの出力を、アンプでモータドライバ向けの指令レベルに整える。
- モータのトルクは電流にほぼ比例：$`\tau = k_t \, I`$。maxon EC 45 flat は**トルク定数 $`k_t \approx 25.5\ \text{mNm/A}`$**。
- つまり「指令電圧↑ → ドライバが流す電流↑ → トルク↑」という連鎖で強さを操ります。
- 回転すると**逆起電力（back-EMF）** $`E = k_e\,\omega`$ が生じ、実際の電流は電源電圧・巻線抵抗・回転数で決まります（回るほど電流は流れにくくなる）。

### パルスカウント：回転を"数えて"読む
- ホール・センサはモータが少し回るごとにパルスを出す。一定時間のパルス数を数えれば回転数がわかる。
- パルスの向き（順・逆）まで見れば回転方向もわかり、ホイールが**飽和**に近いかを監視できます。

### MOSFET：誘導負荷（コイル）のスイッチング
- 電磁ブレーキのコイルは**インダクタンス**を持つ。急に電流を切ると高い逆電圧（スパイク）が出て素子を壊しかねない。
- 対策として**フライバックダイオード**を並列に入れて逃がす。GPIOの小信号でゲートを駆動し、大電流をON/OFFする**ローサイドスイッチ**構成が定番です。
