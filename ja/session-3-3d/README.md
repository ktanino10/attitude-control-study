# 座学 第3回：3次元への拡張

第2回までは「1軸（1次元）」の倒立振子でした。今回はいよいよ、**立方体をコーナー（1点）で立たせて、3方向を同時に制御する**3次元へ拡張します。
やることの骨組みは第2回と同じ。ただし「向きの表し方」「傾きの測り方」「式の大きさ」が3次元らしく進化します。

> **今回の元ネタ**：トランジスタ技術 2020年8月号 短期連載【第3回】3次元の姿勢制御（巳谷 真司／JAXA, pp.140–149）。図は写真を使わず自分で描き直しています。

---

## 今回のゴール
- [ ] 1軸から3軸になると「何が増えるのか」を言える
- [ ] 慣性座標系 {I} と ボディ座標系 {B} のちがいを説明できる
- [ ] オイラー角（ヨー・ピッチ・ロール）で向きを表せることがわかる
- [ ] 加速度センサから傾きが出せる／ヨーは出せない理由が言える
- [ ] 相補フィルタが「2つのセンサのいいとこ取り」だとわかる
- [ ] ヨーが「動かせない・見えない」ので7次元だけ制御する、という話の筋がわかる

## 今回の一枚まとめ

3次元でも、やることの流れは第2回と同じ。**「測る → 向きを決める → 式にする → 制御則を決める」** です。

\`\`\`mermaid
flowchart LR
    A["向きを表す<br/>座標系とオイラー角"] --> B["傾きを測る<br/>加速度センサとジャイロ"]
    B --> C["合成する<br/>相補フィルタ"]
    C --> D["式にする<br/>3次元の状態方程式"]
    D --> E["制御則<br/>7次元だけLQR"]
\`\`\`

> 1軸の「モデリング→線形化→離散化→制御則」（第2回）を、3軸ぶんに拡張しただけ。
> 新しく出てくるのは「座標系の使い分け」「傾きの推定」「ヨーが制御できない問題」の3つです。
