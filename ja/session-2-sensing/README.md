## 📖 学ぶ内容（元記事「キーパーツ①慣性センサ」より）

| トピック | ざっくり内容 | キーワード |
|---|---|---|
| IMUとは | 加速度3軸＋角速度3軸をまとめた「6軸」センサ | IMU / MEMS / MPU-6050 |
| 加速度センサ | 重力の向き＝下を感じる。**ゆっくりの動き（低周波）が得意** | 加速度 / 低周波で誤差小 |
| ジャイロ・センサ | 回るスピード（角速度）を感じる。**素早い動き（高周波）が得意** | 角速度 / ドリフト |
| 2つの弱点 | 加速度＝速い動き・遠心力に弱い／ジャイロ＝時間でズレる（ドリフト） | 遠心力 / 積分の誤差 |
| 合わせ技 | 低周波は加速度、高周波はジャイロ → 合体で全域正確に | センサ・フュージョン |
| カルマン・フィルタ | 2つの不完全な情報を賢く合体して真の姿勢を推定 | カルマン・フィルタ |
| なぜ6個も？ | 統計処理で誤差を減らす＋取り付け位置の差で遠心力も利用 | 冗長化 / 統計処理 |
| 本物の衛星は | スタートラッカ（星）や太陽センサも併用（慣性だけだと誤差が発散） | スタートラッカ / 太陽センサ |
