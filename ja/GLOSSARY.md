# 用語集（ぜんぶ中学生にもわかる言葉で）

**言語 / Language:** 日本語（現在） ・ [English](../en/GLOSSARY.md) ｜ [トップ](../README.md)

記事や姿勢制御で出てくる言葉を、やさしい例えつきでまとめます。
わからない言葉が出たら、ここを引いてください。カテゴリ別に並べています。

## 基本のことば

| 用語 | よみ／英語 | かんたんな意味（例え） |
|---|---|---|
| 姿勢 | しせい／attitude | 「今、どっちを向いているか」。人の"姿勢"と同じで、物体の**向き**のこと。 |
| 姿勢制御 | しせいせいぎょ／attitude control | 向きを**保ったり・変えたり**すること。フィギュアスケーターが回転を止めてピタッと止まるのと同じ発想。 |
| 3軸 | さんじく／3-axis | 向きは**3方向の回転**で表せる。だから「3軸」。 |
| XYZ軸 | — | たて・よこ・おくゆき の3本の基準線。この3本まわりの回転で姿勢が決まる。 |
| ロール | roll | 機体の**前後の軸**まわりの回転（飛行機が左右に傾くやつ）。 |
| ピッチ | pitch | **左右の軸**まわりの回転（おじぎ・機首上げ下げ）。 |
| ヨー | yaw | **上下の軸**まわりの回転（首を左右にふる）。 |
| トルク | torque | **回そうとする力**。ドアノブを回す、レンチでボルトを回すときの"回す力"。 |
| 慣性 | かんせい／inertia | 物が「今の動きを続けたがる」性質。電車が急に止まると体が前に倒れる、あれ。 |
| 角速度 | かくそくど／angular velocity | **回るスピード**。1秒間に何度回るか。 |
| 角運動量 | かくうんどうりょう／angular momentum | 「回りの勢い」。重くて速く回るほど大きい。**外から力がないと勝手に変わらない**（保存される）。 |
| 遠心力 | えんしんりょく／centrifugal force | 回転しているときに**外へ引っぱられる**ように感じる力（バケツを回すと水がこぼれない、あれ）。 |
| 倒立振子 | とうりつしんし／inverted pendulum | **棒を手のひらの上で立てる**遊びと同じ。倒れそうな物をバランスで立て続ける課題。 |

## センサ（自分の向きを"知る"）

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| 慣性センサ / IMU | Inertial Measurement Unit | 「加速度センサ＋ジャイロ」をまとめた部品。**自分の動き・傾き**を感じる。 |
| 加速度センサ | accelerometer | **どっちが下（重力の向き）か**、押される向きを感じるセンサ。スマホを傾けると画面が回るのはコレ。 |
| ジャイロ・センサ | gyroscope | **回っているスピード（角速度）**を感じるセンサ。スマホを回すと反応するのはコレ。 |
| MEMS | メムス | 半導体チップの上に作った**とても小さな機械**。安くて小さいセンサが作れる。 |
| MPU-6050 | — | よく使われるMEMSの6軸センサ（加速度3＋角速度3）。この記事では6個使用。 |
| 6軸 / 36軸 | — | 1個で6軸（加速度3方向＋回転3方向）。6個なので合計36軸ぶんのデータ。 |
| ドリフト | drift | ジャイロの値が**少しずつズレていく**こと。ちょっとの誤差がたまって大きくなる。 |
| ノイズ | noise | センサの値に混じる**でたらめなゆらぎ**（ザラザラ）。 |
| 低周波 / 高周波 | ていしゅうは／こうしゅうは | ゆっくりした変化＝低周波、素早い変化＝高周波。**加速度センサはゆっくり系が得意、ジャイロは素早い系が得意**。 |
| カルマン・フィルタ | Kalman filter | **2つの不完全な情報を賢く合体**して、より正しい答えを出す計算方法。「片方の目が近くに強く、もう片方が遠くに強い→両目で見ると正確」みたいな合わせ技。 |
| センサ・フュージョン | sensor fusion | 複数のセンサを組み合わせて弱点を補うこと。カルマンフィルタはその代表。 |

## アクチュエータ（向きを"変える"）

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| リアクション・ホイール | reaction wheel | 中で**円盤を回す**と、その反動で**本体が逆に回る**装置。回転いすで車輪を回すと自分が逆に回るのと同じ。宇宙でも使える。 |
| 角運動量保存則 | law of conservation of angular momentum | 「回りの勢いの合計は変わらない」というルール。だからホイールを回すと本体が逆に回る。 |
| 作用・反作用 | action-reaction | 押したら押し返される。ホイールを回す力の反対向きの力が本体にかかる。 |
| アンローディング | unloading | 回しすぎたホイールを**元の速さに戻す**操作。ドローンや車の車輪を使って本体に力をかけて調整する。 |
| 電磁ブレーキ | でんじブレーキ／electromagnetic brake | 電気を流すと**磁石の力でホイールに一瞬でくっついて止める**ブレーキ。止めた勢い（回転エネルギ）を一気に力に変えられる。 |
| モータ | motor | 電気で回る部品。ここではホイールを回す。 |
| ブラシレスモータ | brushless motor | こすれる部品（ブラシ）がない高性能なモータ。長持ち・高効率。 |
| EC 45 / maxon | — | この記事で使われたモータの型番／メーカー（マクソン社、30W）。 |
| 定格 | ていかく／rated | 「安全に**ずっと**使える上限」。一瞬なら定格より大きな力も出せる。 |
| モータ・ドライバ | motor driver | マイコンの指令を受けて、モータに**流す電流を調整**する部品。モータの"アクセル係"。 |
| 駆動電流 | くどうでんりゅう | モータに流す電流。多いほど強いトルクが出る。 |

## 電子回路・マイコンまわり

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| マイコン | microcontroller | 小さなコンピュータ。全体の**司令塔（脳）**。 |
| PSoC 5LP | ピーソック | この記事で使われたマイコン。中に色々な回路を**プログラムで作れる**のが特徴。 |
| ARM Cortex-M3 | — | PSoC 5LP の中に入っている計算の心臓部（CPUの種類）。 |
| CPU | シーピーユー | 計算・判断をする部分。 |
| D-Aコンバータ | DAC | **デジタル（数字）→アナログ（電圧の大小）**に変換する部品。マイコンの指令を電圧に直す。 |
| ホール・センサ | Hall sensor | 磁石の向きから**モータの回転**を検知する。出力パルスを数えて回転数を知る。 |
| MOSFET | モスフェット | 電気の**スイッチ**（大きな電流を素早くON/OFFする部品）。電磁ブレーキのON/OFFに使う。 |
| I²C | アイスクエアドシー | チップ同士が**2本の線でおしゃべり**する通信ルール。センサとマイコンの会話に使う。 |
| UART | ユーアート | もう1つの**シリアル通信**のルール。無線モジュールとの会話に使う。 |
| GPIO | ジーピーアイオー | マイコンの**汎用の入出力ピン**。ON/OFFの信号などに使う。 |
| リアルタイムOS | RTOS | 「**決まった時間内に必ず処理する**」ことを大事にする基本ソフト。姿勢制御は時間が命なので使う。 |
| FreeRTOS | フリーアルトス | よく使われるリアルタイムOSの名前。 |
| UDB | Universal Digital Block | PSoCの中の「**自由に回路を作れるブロック**」。 |
| リチウムポリマ電池 | LiPo | 軽くて容量の大きい充電池。ここでは7.4Vを2個。動力源。 |
| 無線モジュール | wireless module | リモコンと電波でやりとりする部品。 |

## 数学の基本（線形・行列・微分・固有値）

座学2以降で出てくる数学の言葉を、いちばんやさしく。ここが分かると式の"気持ち"が読めます。

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| 線形 | せんけい／linear | 「入力を2倍にしたら答えも2倍」の素直な関係。グラフにすると**まっすぐな直線**。足し算と定数倍だけでできていて、**重ね合わせ**（別々に解いて足せる）が使える。 |
| 非線形 | ひせんけい／nonlinear | 直線でないもの。$`\sin\theta`$・2乗・掛け算どうし（$`\theta\times\omega`$）など。**比例しない**ので、決まった公式で一発では解けない。 |
| 近似 | きんじ／approximation | むずかしいものを、扱いやすい**近いもの**に置きかえること。「倒立点の近くだけ $`\sin\theta\approx\theta`$」がその例。 |
| ベクトル | vector | 数を縦に並べた組。バラバラの状態（傾き・角速度…）を**1つにまとめて** $`\mathbf{x}`$ と書く道具。 |
| 行列 | ぎょうれつ／matrix | 数を長方形に並べた表。**たくさんの連立式を1個にまとめる**道具。$`A\mathbf{x}`$ で「各状態がどれだけ効くか」を一気に計算できる。 |
| 微分 | びぶん／derivative | **変化の速さ**。$`\dot{x}`$（エックスドット）は「$`x`$ が1秒でどれだけ変わるか」。角度の微分＝角速度。 |
| 積分 | せきぶん／integral | 変化を**足し集めて**元の量に戻すこと。角速度を積分すると角度。相補フィルタや離散化で使う。 |
| 固有値 | こゆうち／eigenvalue | 行列 $`A`$ の"クセ"を表す数。**プラスなら勝手に増える（不安定）／マイナスなら収まる（安定）**。倒立振子は固有値がプラスなので放っておくと倒れる。 |

## 運動方程式とマイコン制御（座学2）

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| 運動方程式 | うんどうほうていしき／equation of motion | 「力・トルクを受けて物がどう動くか」を表す式。ニュートンの法則を回転に当てはめたもの。 |
| モデリング | modeling | 現実の動きを**数式のルール**に置きかえる作業。制御の第一歩。 |
| 摩擦トルク | まさつトルク／friction torque | 回転をじゃまする摩擦の力。速さに比例する分（粘性）などを式に入れる。 |
| 線形化 | せんけいか／linearization | 倒立点の**近くだけ**を見て、曲線（sinθ など）を**直線**に近似すること。 |
| テイラー展開 | テイラーてんかい／Taylor expansion | 関数を「1次＋2次＋…」の足し算で表す方法。小さい高次の項を捨てると線形化できる。 |
| 平衡点（倒立点） | へいこうてん／equilibrium point | 力がつり合って「そのままなら止まっていられる」姿勢。倒立振子ではまっすぐ立った点。 |
| 状態空間モデル | じょうたいくうかん／state-space model | 状態をベクトルにまとめ、$`\dot{x}=Ax+Bu`$ の形で表した式。行列で一気に扱える。 |
| 状態変数 | じょうたいへんすう／state variable | 「今の状態」を表す数の集まり（例：傾き・角速度・ホイール速度）。ベクトル $`x`$。 |
| 離散化 | りさんか／discretization | 連続時間の式を、一定間隔（20ms）ごとの式 $`x[k{+}1]=A_d x[k]+B_d u[k]`$ に直すこと。 |
| サンプリング周期 | sampling period $`\Delta t`$ | センサを読んで計算して出力する**1コマの時間**。この機体では20ms。 |
| 状態フィードバック | state feedback | 今の状態 $`x`$ を見て入力を $`u=-Kx`$ と決める制御。「傾いた分だけ逆に押し返す」。 |
| ゲイン | gain $`K`$ | 「どれだけ強く押し返すか」の強さ設定。大きいほどキビキビ動く。 |
| LQR | エルキューアール／Linear Quadratic Regulator | ゲイン $`K`$ を、評価関数 $`J`$（ズレと入力のペナルティ）を最小にするよう自動で決める方法。 |

## 3次元への拡張（座学3）

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| 姿勢推定 | しせいすいてい／attitude estimation | センサの値から「今どれだけ傾いているか」を割り出すこと。 |
| 最小二乗法 | さいしょうにじょうほう／least squares | たくさんの測定値に**いちばん合う答え**を求める計算。6個の加速度から重力の向きを出すのに使う。 |
| ジャイロ効果 | gyroscopic effect | 3次元で回転が**おたがいに影響し合う**効果。$`\omega\times(I\omega)`$ の項として現れる。 |
| 慣性テンソル | かんせいテンソル／inertia tensor | 3次元版の慣性モーメント。方向ごとの回しにくさを表す**3×3の表**。 |
| 状態方程式 | じょうたいほうていしき／state equation | $`\dot{x}=Ax+Bu`$ の形の式。3次元では状態が9個に増える。 |
| 可制御性 | かせいぎょせい／controllability | 入力（モータ）で状態を**思いどおりに動かせるか**。この機体ではヨーが動かせない。 |
| 可観測性 | かかんそくせい／observability | センサから状態を**言い当てられるか**。ヨーは重力から見えない。 |
| カルマン正準分解 | Kalman canonical decomposition | 系を「動かせて見える部分／そうでない部分」に整理する方法。7次元の部分だけ制御に使う。 |

## くわしく編（一歩踏み込む用語）

「くわしく」パートに出てくる、少し専門的な言葉です。

| 用語 | よみ／英語 | かんたんな意味 |
|---|---|---|
| 自由度 | じゆうど／DOF | 独立に動ける方向の数。空間の剛体は移動3＋回転3で**6自由度**。姿勢は回転の3自由度。 |
| 機体座標系 | body frame | 装置に貼りついた軸。センサはこの軸で測る。 |
| 慣性座標系 | inertial frame | 宇宙に固定した"動かない"基準。姿勢はこの基準に対する回転で表す。 |
| オイラー角 | Euler angles | ロール・ピッチ・ヨーのように**3つの角度**で向きを表す方法。直感的だがジンバルロックの弱点あり。 |
| クォータニオン | quaternion | **4つの数**で向きを表す方法。順番や特異点に強く、実機で多用。 |
| ジンバルロック | gimbal lock | オイラー角で、ある向きになると軸が重なり回転を表せなくなる現象。 |
| 慣性モーメント | moment of inertia $`I`$ | **回しにくさ**。質量が回転軸から遠い（外側）ほど大きい。単位 kg·m²。 |
| 向心加速度 | centripetal accel. | 回転中に中心へ向かう加速度 $`a=\omega^2 r`$。分散IMUが回転を検知する手がかり。 |
| モメンタム飽和 | momentum saturation | ホイールが上限速度に達し、もう加速できない状態。アンローディングが必要になる。 |
| 磁気トルカ | magnetic torquer | **地磁気**を利用して外部トルクを作る装置。宇宙でのアンローディングに使う。 |
| 外乱トルク | disturbance torque | 姿勢を狂わせる小さな邪魔な力（重力傾斜・太陽光圧・大気抵抗など）。 |
| フィードバック制御 | feedback control | 「測る→目標と比べる→直す」を繰り返して状態を保つ制御。 |
| PID制御 | PID control | 誤差の大きさ・ためこみ・変化速度の3つを使う定番の制御法（→座学3）。 |
| 相補フィルタ | complementary filter | 加速度センサ（低周波）とジャイロ（高周波）を**周波数で役割分担**して合体する簡単な推定法。 |
| 逆起電力 | back-EMF $`E=k_e\omega`$ | モータが回ると発生する"逆向きの電圧"。速いほど電流が流れにくくなる。 |
| PGA | Programmable Gain Amplifier | ゲイン（増幅率）をプログラムで変えられるアンプ。D-A出力をモータドライバ向けに整える。 |
| トルク定数 | torque constant $`k_t`$ | 電流1Aあたりのトルク。maxon EC 45 flat で約 25.5 mNm/A。$`\tau=k_t I`$。 |
| オープンドレイン／プルアップ | open-drain / pull-up | I²Cの配線方式。線を"引き上げる"抵抗（プルアップ）が必要。 |
| フライバックダイオード | flyback diode | コイル（電磁ブレーキ）を急に切ったときの逆電圧から素子を守る部品。 |
