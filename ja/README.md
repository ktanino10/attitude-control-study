# 3軸姿勢制御 まなびノート

**言語 / Language:** 日本語（現在） ・ [English](../en/README.md) ｜ [トップ](../README.md) ・ [参考文献](../REFERENCES.md)

趣味で **3軸姿勢制御（3-axis attitude control）** を学び、いずれ自分でも作れるようになるための勉強ノートです。
むずかしい専門用語を、**中学生にもわかる言葉**でぜんぶかみくだいて説明します。

> **元ネタ（出典）**: トランジスタ技術 2020年6〜8月号 短期連載「XYZ 3軸姿勢制御モジュールの運動方程式とマイコン制御」（全3回、巳谷 真司／JAXA）。各回の詳しい出典は [`REFERENCES.md`](../REFERENCES.md) を参照。
> このノートは記事の写真は使わず、**自分で描いた図**と**自分の言葉のまとめ**だけで作っています。

- 元ネタとの対応は [`coverage-map.md`](./coverage-map.md)、出典は [`REFERENCES.md`](../REFERENCES.md) を参照。

### 2つのレベルで書いています
- **やさしく**：中学生向けの例え中心。まず全体像をつかむ用。
- **くわしく**：もう少し知りたい人向け。物理の式や電気の理屈で"なぜそうなるか"まで。
- 数式は GitHub 上できれいに表示されます（$`\LaTeX`$ 記法）。むずかしければ「くわしく」は飛ばしてOK。

## 式の地図（1本の背骨）

式は「基礎 → 1軸で立てる → 3軸へ広げる」と、**1本の線でつながっています**。番号は元記事の式番号（基礎式1–6はこのノートで付けた通し番号）。

```
基礎式1–6（第1回：回す物理）
   │  L=Iω, 保存, τ=Iω̇, 反作用, E=½Iω², τ=ΔL/Δt
   ▼
式9,10,12（第2回・モデル化：運動方程式＋モータ）
   ▼  sinθ≈θ で直線に（非線形→線形）
式13（線形化：ẋ=Ax+Bu）
   ▼  1コマ先を予測（前進オイラー）
式16–18（離散化：x[k+1]=A_d x+B_d u）
   ▼  u=−Kx を代入＝閉ループ
式19（状態フィードバック＋LQR）
   ▼  3軸へ拡張
式36,37（第3回：傾き推定＋相補フィルタ）
   ▼  基礎式1,3 のベクトル版＝オイラーの方程式
式39,41,42（3次元の運動方程式：ジャイロ項・慣性テンソル・9次元）
```

| つながり | どこで | ひとこと |
|---|---|---|
| 基礎式1–6 → 式9,10 | [第2回 02](./session-2-modeling/02-modeling.md) | 回す物理を1軸の運動方程式に |
| 式10 → 式13 | [第2回 03](./session-2-modeling/03-linearization.md) | `sinθ≈θ` で非線形→線形、A,B を作る |
| 式13 → 式16 | [第2回 04](./session-2-modeling/04-discretization.md) | 前進オイラーで「1コマ先」に |
| 式16 → 式19 | [第2回 05](./session-2-modeling/05-control-law.md) | `u=−Kx` を代入＝閉ループ、固有値で安定化 |
| 基礎式3 → 式39 | [第3回 05](./session-3-3d/05-3d-equations.md) | `τ=Iω̇` に `ω×(Iω)`（ジャイロ項）が加わる |
| 基礎式2 → ヨー | [第3回 06](./session-3-3d/06-controllability-lqr.md) | 保存＋循環座標でヨーは可制御から外れる |
