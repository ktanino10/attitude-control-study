## 🧩 今回の一枚まとめ

マイコンの制御プログラムは、この**4ステップ**で作ります。

```mermaid
flowchart LR
    A["1. モデリング<br/>運動方程式を立てる"] --> B["2. 線形化<br/>倒立点まわりで直線に"]
    B --> C["3. 離散化<br/>20msごとの式に直す"]
    C --> D["4. 制御則を決める<br/>u = -K x をコーディング"]
```

> ①現実の動きを式にして（モデリング）→ ②扱いやすく直して（線形化・離散化）→ ③その式をもとに「どう動かすか」を決める（制御則）。
> この順番は、他のロボットや機械の制御でも共通の"王道"です。
