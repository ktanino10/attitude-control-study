## 🧩 今回の一枚まとめ

姿勢制御は、この3ステップの**くり返し**です。

```mermaid
flowchart LR
    A["① 知る<br/>今どっちを向いてる？<br/>（センサ）"] --> B["② 考える<br/>どれだけズレてる？<br/>（マイコン）"]
    B --> C["③ 動かす<br/>ホイールを回して直す<br/>（アクチュエータ）"]
    C --> A
```

> このループを1秒に何百回も回して、倒れる前に少しずつ直し続ける。
> だから、細い点の上でも立っていられる。
